# Agent working agreement

Build PhairDLNA as a best-in-class, beginner-understandable Rust project. Prefer clear, short modules and descriptive names over clever abstractions. Keep configuration centralized and update WHERE_TO_CHANGE.md.

Operate milestone-by-milestone. Propose a concise plan, implement, test, inspect failures and fix them. Report verified facts separately from assumptions. No placeholder features, fake test results or silent scope reductions. Security and documentation are mandatory acceptance criteria.

Rust-first; preserve headless portability and macOS-first UX. Maintain dependency license review (AGPL-3.0-or-later), threat model, compatibility matrix and regression tests. Keep GitHub Actions manual-only unless owner explicitly changes policy. Do not create public releases or tags without explicit authorization.
