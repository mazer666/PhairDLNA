# Roadmap (proposed; not implemented)

- **M0 Foundation:** approved requirements, architecture, security model, license, Rust workspace, documentation and manually triggered CI.
- **M1 macOS headless DLNA:** discovery, browsing, direct-play streaming, seek, first real-client tests.
- **M2 Library and UX:** incremental index, metadata, native macOS menu bar app, local admin and diagnostics.
- **M3 Linux/Windows:** service integration, packaging, portability and platform tests.
- **M4 Interoperability/hardening:** device profiles, conformance matrix, fuzzing, load and soak tests.
- **M5 Optional transcoding:** resource-bounded codec integration, hardware acceleration where feasible, subtitle optimization.

Each milestone needs evidence-based acceptance, docs and a release gate. No public release/tag without explicit approval.
