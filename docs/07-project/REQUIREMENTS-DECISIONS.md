# Requirements decisions needing evaluation

Status: Open. Do not assume approval.

1. Is v1 macOS-only or must headless Linux/Windows be included in v1?
2. Is transcoding excluded from v1 or optional when a maintained compatible codec tool is present?
3. Which macOS minimum version and support lifecycle?
4. Which DLNA client families and physical devices form the mandatory certification-like compatibility matrix?
5. Is local web administration needed in v1 alongside the native app?
6. Which media formats/subtitle variants are contractual v1 commitments vs best effort?
7. Should remote access remain explicitly out of scope for v1?
8. What languages are mandatory for v1?
9. Which performance reference hardware and network topology define release targets?

Agents should research and recommend defaults with rationale, not block work on every question.
