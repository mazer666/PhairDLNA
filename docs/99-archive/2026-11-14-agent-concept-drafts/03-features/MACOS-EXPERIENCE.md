# F-MAC — macOS native experience

Status: Draft.

MAC-001 Native menu-bar control with start/stop/status and opening settings.
MAC-002 First-run flow: choose folders, review LAN sharing, start service and verify discovery.
MAC-003 Explicit login-start option, reversible and visible; service behavior defined when GUI exits.
MAC-004 Clear macOS network/firewall/permissions guidance without bypassing OS protections.
MAC-005 Apple Silicon and Intel builds with signed/notarized distribution plan before stable.
MAC-006 Keyboard, VoiceOver and scalable UI support.
MAC-007 Local administration never exposed to LAN by default.
MAC-008 Updates do not silently enable telemetry or external connections.

Acceptance: novice usability study per UX-001, keyboard/VoiceOver checklist, app lifecycle and sleep/wake tests, clean install/uninstall and permission-denial scenarios.
