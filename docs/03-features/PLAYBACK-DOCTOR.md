# F-DOCTOR — Guided Playback Doctor

Status: Proposed signature feature, not yet approved.

DOC-001 Classify failures: discovery, browse, access, codec/container, subtitles, seek, network, permissions, index and resource exhaustion.
DOC-002 Show user-friendly symptom, likely cause, confidence and actionable next step; technical detail on demand.
DOC-003 Never change firewall, interface, media files, system permissions or router settings without explicit user confirmation.
DOC-004 Export a minimal, redacted, locally generated support bundle after preview/consent.
DOC-005 Allow user to undo reversible configuration repairs and see what changed.
DOC-006 Clearly indicate when cause is unknown; no fabricated diagnostics.

Acceptance: 10 scripted failure cases with expected classifications, remediation and safety; >=80% novice comprehension target in controlled study; negative tests for sensitive log leakage and unsafe remediation.
